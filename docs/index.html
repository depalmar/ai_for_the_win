What you need

  • Python 3.10 or later on Windows, macOS or Linux
  • A code editor: VS Code, Cursor or PyCharm
  • 8 GB of RAM, or 16 GB to run LLMs locally
  • Git, to clone the repository
  • An API key only from lab 14 on. Free tiers and Ollama both work.
  • Basic security concepts help but are not required

Why this course

  • Built for security practitioners: every lab solves a security problem, from phishing and malware to C2 and incident response.
  • You build tools you can use: classifiers, agents, RAG systems and detection pipelines.
  • Designed for AI-assisted development with Claude Code, Cursor and Copilot.
  • Learn ML foundations before spending on LLM APIs, or spend $0 with Ollama.
  • New to Python? Start at lab 00. The Security-to-AI glossary translates ML jargon into terms you know.

Frequently asked questions

Do I need prior ML or AI experience?
No. Labs 00 to 09 cover Python basics, ML concepts and prompt engineering from scratch. The Security-to-AI glossary translates ML jargon into security terms you already know.
Which LLM provider should I use?
We recommend Anthropic Claude for security tasks: Sonnet for everyday lab work, Opus for the hardest reasoning. All labs also support OpenAI GPT, Google Gemini and Ollama (free, local). You only need one provider. See the LLM provider comparison for current models and pricing.
Can I run everything locally without API costs?
Yes. Use Ollama to run models locally for free. Labs 00 to 13 need no API at all, so you can complete the whole course for $0 with local models.
How long does it take to complete all labs?
About 40 to 89 hours, depending on experience and how much you use AI assistance. With AI coding tools such as Cursor or Claude Code, most labs take 50 to 70 percent less time. Start with your role's learning path, about 5 to 18 hours, for the quickest return.
What if I get stuck on a lab?
Every lab includes complete solution code and hints, most have a step-by-step walkthrough, and most have a Colab notebook you can run in your browser. Ask in GitHub Discussions or open an issue.
Can I use this commercially?
Documentation and labs are licensed CC BY-NC-SA 4.0 (non-commercial); code samples are MIT. For commercial use, see commercial licensing. The solutions demonstrate core concepts; for production you would add error handling, logging and scale.
How is this different from other ML courses?
Every lab solves a real security problem. You will not build iris classifiers or digit recognizers; you will build phishing detectors, threat intel agents and ransomware analyzers.

Docker, recommended

One command starts Jupyter, Elasticsearch, Kibana, PostgreSQL, Redis, MinIO, Ollama and ChromaDB.

git clone {{ repo }}.git
cd ai_for_the_win/docker
docker compose up -d
# Jupyter Lab at http://localhost:8888 (token: aiforthewin)

Local install

Python 3.10 or later and a virtual environment.

git clone {{ repo }}.git
cd ai_for_the_win
python -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt
python labs/lab10-phishing-classifier/solution/main.py
